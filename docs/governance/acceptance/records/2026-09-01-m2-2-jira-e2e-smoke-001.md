# M2.2 真实 Jira 端到端只读 Smoke 验收记录

## Scope

**Included**

- 在 `PILOT` 模式下，对 Jira CLI 已配置的单一默认项目执行一次最多 20 条的只读同步。
- 通过受鉴权 Backend API 创建 Sync Run，由 `IssueSyncJobWorker` 调用 Jira CLI Adapter，并由 PostgreSQL 事务持久化事实、Job、Audit、Outbox 与 successful Cursor。

## Recommended Decision

建议 `CONDITIONAL`：接受 `Jira → Backend API/Worker → PostgreSQL → successful Cursor` 的真实只读端到端链路已经跑通；不接受“公司 Jira 状态语义映射已经可用于质量判定”。条件关闭需要完成脱敏状态映射设计、固定 Adapter 版本权威、Fixture 回归，并通过单独授权的最小真实复测。

## Decision Reason

Project Owner 对 `M2-2-JIRA-E2E-SMOKE-001` 作出条件验收。被接受的事实是 `Jira → Backend API/Worker → PostgreSQL → successful Cursor` 的单项目、最多 20 条真实只读链路已成功执行，Sync Run、Job、PostgreSQL facts、successful Cursor、Audit 与 Outbox 均有脱敏证据。

本决定不接受公司 Jira 状态语义已经可用于质量判断：本次 20 条 normalized status 均为 `UNKNOWN`，必须先建立不改变 Issue Contract、未知值继续 fail-visible 的可配置映射并通过 Fixture 回归。本决定同时不接受 Adapter 版本权威已完成；`jira-cli-pilot-v1` 与既有记录中的 `jira-cli-pilot-adapter-v1` 必须统一到单一配置或常量来源。

条件关闭后仍需取得独立授权才能执行最小真实复测。本决定不授权 Jira 写入、第二项目、超过 20 条查询、Task 5、Company Profile、合并 `main`/`release`、创建 Tag、发布或生产部署，也不修改任何 V0.1 冻结架构。
